# Kessler Electric website

This is the standalone React + GSAP version of the Kessler Electric website.

## Run locally

Node.js 22.12 or newer is recommended.

```bash
npm install
npm run dev
```

Open the local address printed in the terminal.

## Build for your hosting service

```bash
npm run build
```

Upload the contents of the generated `dist` folder to your web host. You can test that production build locally with:

```bash
npm run preview
```

## Main folders

- `src/` contains the React component and website styles.
- `public/` contains the images, favicon, and social sharing image.
- `dist/` is generated by `npm run build` and is the folder intended for hosting.
